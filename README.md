# Bryntum Gantt with tasks data in Zustand store example

## Backend: Express backend for Bryntum Gantt

This Express app has API endpoints to load Gantt data and sync data changes to a local SQLite database. It uses [Sequelize ORM](https://sequelize.org/).

Install the dependencies using the following command:

```shell
npm install
```

Seed the database with the example tasks data:

```shell
npm run seed
```

Run the local development server:

```shell
npm run dev
```

# Frontend: Bryntum Gantt with Zustand 

Install the dependencies using the following command:

```shell
npm install
```

⚠️ You need a Bryntum licence to install the Bryntum Gantt dependency. If you don't have one, install the [trial package](https://bryntum.com/products/gantt/docs/guide/Gantt/integration/javascript/multiple-products).

Run the local development server:

```shell
npm run dev
```
